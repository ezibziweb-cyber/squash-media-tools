Privacy Policy

Last updated: 22 October 2026

Squash Media Tools ("the app") is an internal tool operated by Squash Media Inc. It is used only by Squash Media to manage YouTube channels that Squash Media owns.

What the app accesses

When a channel owner signs in with Google, the app asks for permission to read that channel's YouTube data and YouTube Analytics reports, and to upload videos to that channel. It uses these permissions only to show the channel's own statistics to Squash Media and to upload Squash Media's own approved videos.

How data is stored

Sign-in tokens and statistics are stored only on Squash Media's own computer. They are not stored on any public server.

Sharing

The app does not sell, rent or share any data with anyone. It does not use Google user data for advertising.

Google API Services

The app's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Removing access

Access can be removed at any time from the Google Account permissions page: myaccount.google.com/permissions.

Contact

Questions about this policy: use the support email shown on the app's Google sign-in screen.
